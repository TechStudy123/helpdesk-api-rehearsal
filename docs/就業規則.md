# みらい商事 就業規則（抜粋）

※この資料は、このコースの学習用に作った架空のものです。実在の会社・規則とは関係ありません。

## 第1章 総則

第1条 目的
この規則は、みらい商事株式会社（以下「会社」）の社員の働き方と、守るべき決まりを定める。

第2条 適用
この規則は、会社に雇われているすべての社員に適用する。パートタイムの社員には、別に定める規程も適用する。

## 第3章 勤務時間と休日

第8条 勤務時間
始業は午前9時、終業は午後6時とする。休憩は正午から午後1時までの1時間とする。

第9条 休日
休日は、土曜日、日曜日、国民の祝日、年末年始（12月29日から1月3日まで）とする。このほか、会社が定める夏季休暇を3日与える。

第10条 フレックスタイム制
会社が認めた部署では、フレックスタイム制で働くことができる。必ず勤務する時間（コアタイム）は、午前11時から午後3時までとする。

## 第4章 休暇

第11条 年次有給休暇
入社して6か月たった社員には、10日の年次有給休暇を与える。その後は1年ごとに、勤続年数に応じて日数を増やし、最大で20日とする。使わなかった日数は、翌年度まで繰り越すことができる。

第12条 有給休暇の申請
有給休暇を取るときは、前日までに勤怠システムから申請する。ただし、急病の場合は、当日の始業時刻までに上長へ電話またはチャットで連絡し、出社したあと、すみやかに勤怠システムから申請すればよい。

第13条 特別休暇
次の場合は、有給休暇とは別に、給与が支払われる特別休暇を与える。
本人が結婚するとき 5日
配偶者が出産するとき 2日
親族が亡くなったとき 1日から5日（続柄による）

第14条 リモートワーク
リモートワークは、週に3日まで認める。前の週の金曜日までに、勤怠システムから予定を申請する。自宅以外の場所で働くときは、上長の許可を得る。

## 第5章 服務

第15条 情報の取り扱い
社外秘の資料や、お客さまの個人情報を、会社が認めていない外部のサービス（生成AIのサービスを含む）に入力してはならない。

第16条 副業
副業をするときは、始める前に、人事部に届け出る。会社と競合する仕事は、してはならない。
